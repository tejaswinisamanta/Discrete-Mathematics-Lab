# Discrete Mathematics

1) Expressing relations as ordered pairs and creating relations.

2) Finding whether or not a given relation is: 
* Reflexive
* Antisymmetric
* Transitive
* Partial order

3) Finding the following for a given partially ordered set 

* Covering relations.
* The corresponding Hasse diagram representation.
* Minimal and maximal elements.

4) Finding the following for a subset S of a given partially ordered set P <br>
* Whether a given element in P is an upper bound (lower bound) of S or not.
* Set of all upper bounds (lower bounds) of S.
* The least upper bound (greatest lower bound) of S, if it exists.

5) Creating lattices and determining whether or not, a given partially ordered set is a lattice. <br>

6) Finding the following for a given Boolean polynomial function: <br>
* Representation of Boolean polynomial function and finding its value when the Boolean variables in it take particular values over the Boolean algebra {0,1}.
* Display in table form of all possible values of Boolean polynomial function over the Boolean algebra {0,1}.

7) Finding the following:
* Dual of a given Boolean polynomial/expression.
* Whether or not two given Boolean polynomials are equivalent.
* Disjunctive normal form (Conjunctive normal form) from a given Boolean expression.
* Disjunctive normal form (Conjunctive normal form) when the given Boolean polynomial function is expressed by a table of values.

8) Representing a given circuit diagram (expressed using gates) in the form of Boolean expression.

9) Minimizing a given Boolean expression to find minimal expressions.
